# EntityVitals.HasHpObservation property

True once a REAL current-HP value has been observed for this entity (an `AttrHp` carrying `hp >= 0`, including 0 = dead). A MaxHp-only observation leaves this `false` while [`IsKnown`](./IsKnown.md) is already `true` — such an entity is "alive, HP unknown", NOT dead. Death inference (e.g. a meter's dead styling, wipe detection) must require this flag before reading [`Hp`](./Hp.md) &lt;= 0 as death. Init-only (not a constructor parameter) so plugins compiled against older Abstractions keep binary compatibility.
