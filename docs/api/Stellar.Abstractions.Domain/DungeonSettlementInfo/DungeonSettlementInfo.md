# DungeonSettlementInfo constructor

Settlement (clear/result) summary for a dungeon run, decoded from `WorldNtf.SyncDungeonData.settlement`. Present only once a run reaches its result screen; until then [`LastSettlement`](../../Stellar.Abstractions.Services/IDungeonState/LastSettlement.md) is `null`.

```csharp
public DungeonSettlementInfo(int PassTimeSeconds, int MasterModeScore, int TotalScore)
```

| parameter | description |
| --- | --- |
| PassTimeSeconds | Clear time in seconds (`DungeonSettlement.pass_time`). |
| MasterModeScore | Master-mode MAX/PAR score (`DungeonSettlement.master_mode_score`, field 5); 0 when not a scored/master run. |
| TotalScore | The ACHIEVED "Total Score" the settlement screen shows (`DungeonScore.total_score`, field 14); the numerator in the "686/700" pairing. 0 when not a scored run. |
