# DungeonSettlementInfo structure

Settlement (clear/result) summary for a dungeon run, decoded from `WorldNtf.SyncDungeonData.settlement`. Present only once a run reaches its result screen; until then [`LastSettlement`](../Stellar.Abstractions.Services/IDungeonState/LastSettlement.md) is `null`.
