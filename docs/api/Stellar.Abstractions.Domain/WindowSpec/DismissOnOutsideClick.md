# WindowSpec.DismissOnOutsideClick property

When true the framework auto-hides this window on Escape or a mouse press outside its rect — the click-away dismiss a cursor popup / context menu wants. The dismiss invokes the registration's `OnClose` (wire it to [`SetVisible`](../../Stellar.Abstractions.Services/IWindowControl/SetVisible.md)(false)); with no OnClose the flag is inert. Handled on the per-render-frame interaction ticker, NOT the throttled framework tick, so it never misses a one-frame click/key edge (a press lasting one rendered frame would be missed by a plugin polling input from its throttled OnUpdate).
