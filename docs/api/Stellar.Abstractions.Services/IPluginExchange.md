# IPluginExchange interface

The sanctioned inter-plugin communication channel. One plugin [`Provide`](./IPluginExchange/Provide.md)s an implementation of a contract interface; another [`Consume`](./IPluginExchange/Consume.md)s it — without the two plugins referencing each other (the framework is their only shared reference). The framework brokers purely by Type and never references any contract type, so this surface stays plugin-agnostic — it is the ONE generic extension point; specific contracts live in a shared contracts assembly (e.g. `Stellar.PluginContracts`), never here. Late-bind: `Consume` at use-time (not construction) so plugin load order does not matter.
