# IEntityTransforms interface

Toolkit service that reads the live world transform (position + facing) of an arbitrary game entity by id. Backed by the game's entity manager; reads MUST happen on the main thread (the framework [`Update`](./IFramework/Update.md) tick). Intended for replay/position capture; returns `false` when the entity is not resolvable (despawned, not loaded, or off-game), leaving the out-parameters at their defaults.
