# DropdownElement constructor

Compact dropdown for a small, fixed set of mutually-exclusive choices (e.g. a mode selector) — a reusable replacement for a click-to-cycle button. The trigger shows the current option (caption + ▾); a click opens a themed floating option list that floats above the window's scroll clip. Picking an option calls *OnSelect* with its index; the list dismisses on pick, outside-click, or Esc.

```csharp
public DropdownElement(Func<int> Selected, Func<IReadOnlyList<string>> Options, 
    Action<int> OnSelect, float Width = 0)
```

| parameter | description |
| --- | --- |
| Selected | Current selected index (poll-diffed); out of range → empty caption. |
| Options | Option captions in order; the index passed to *OnSelect* indexes this list. |
| OnSelect | Invoked with the picked option's index. |
| Width | Fixed trigger width in px; 0 → sized to the current caption like a normal button. |
