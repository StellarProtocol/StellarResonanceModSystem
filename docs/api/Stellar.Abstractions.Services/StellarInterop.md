# StellarInterop class

Static IL2CPP-interop reflection floor shared by every plugin. Pure BCL reflection over the live AppDomain — no Unity / game / HarmonyX references — so it lives in the contract layer alongside `VirtualListMath` and can be called from static Harmony patch classes that hold no [`IPluginServices`](./IPluginServices.md) handle.

IL2CPP notes: il2cpp fields surface as PropertyInfo (never FieldInfo); il2cpp lists (`ZList<T>`) are not IEnumerable, so walk them with [`Count`](./StellarInterop/Count.md) + [`Item`](./StellarInterop/Item.md); `ZSingleton<T>.Instance` is an inherited static member reachable via the base-chain walk in [`GetSingleton`](./StellarInterop/GetSingleton.md).
