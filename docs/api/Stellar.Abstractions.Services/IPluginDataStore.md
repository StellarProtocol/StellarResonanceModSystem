# IPluginDataStore interface

Per-plugin binary file storage for data too large or too opaque for [`IConfigSection`](./IConfigSection.md) (which holds only primitives, arrays, and dictionaries). Each plugin gets its own directory (`<plugins-dir>/<pluginGuid>.data/`); names are relative to it. A `name` may contain at most one `/` separating a single subdirectory from the file (e.g. `replay/123-456.gz`); `..`, rooted paths, and backslashes are rejected. Every method is best-effort and NEVER throws — IO faults are logged and swallowed.
