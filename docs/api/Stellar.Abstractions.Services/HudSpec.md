# HudSpec record

A plugin's HUD: stable id, anchor, and the root element to render. Visibility is owned entirely by [`ShouldRender`](./HudSpec/ShouldRender.md) (the single source of truth — `hide = !ShouldRender()`); a gameplay HUD hides itself when covered by reading `UiState` in that predicate. *DefaultRect* is the spawn position used on first run / when no layout is saved for the current resolution (clamped on-screen by the layout layer); null falls back to the renderer's initial placement (top-left).
