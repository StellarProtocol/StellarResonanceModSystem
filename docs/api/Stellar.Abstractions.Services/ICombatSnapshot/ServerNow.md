# ICombatSnapshot.ServerNow property

The same interpolated server clock as [`ServerNowMs`](./ServerNowMs.md) exposed as a wall-clock DateTimeOffset in the server time domain (server epoch mapped onto local monotonic time, so it advances smoothly between the ~5 s SyncServerTime anchors). Reads the Unix epoch (1970) until the first server-time observation, matching the `ServerNowMs == 0` "no server time yet" contract.
