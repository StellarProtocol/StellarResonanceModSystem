# IHarmonyHost interface

Per-plugin owner of Harmony instances. Plugins still author their own patch classes, but obtain the Harmony from here so the framework guarantees id uniqueness (namespaced to the plugin) and unpatches every instance automatically when the plugin is disposed — a plugin can no longer leak an un-unpatched instance across a soft enable/disable cycle. Pairs with [`FindMethod`](./StellarInterop/FindMethod.md) for resolving patch targets.
