# IEntityDetail.RefreshSocialSnapshot method

Ask the game to re-fetch this player's social data (master score, guild, portraits) by originating its own `Social.GetSocialData` request. Fire-and-forget: the refreshed snapshot arrives asynchronously via the wire-tap and replaces the cached value — poll [`GetSocialSnapshot`](./GetSocialSnapshot.md) to observe it. No-op for non-player entities.
