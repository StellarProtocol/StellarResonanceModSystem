# IInventory.GetLiveEquipped method

The LOCAL player's CURRENT LIVE equipped gear + modules, read from the game's live equip/mod containers — so it reflects manual equips, refines, and class-swap re-equips (unlike [`GetSelfGear`](./GetSelfGear.md), which is a stale method-21 full-sync cache). Gear carries rolls + refine + enchant; modules carry rolled parts keyed by slot. Empty lists until the container resolves. Re-read on [`SelfGearChanged`](./SelfGearChanged.md) to capture a change as it happens.
