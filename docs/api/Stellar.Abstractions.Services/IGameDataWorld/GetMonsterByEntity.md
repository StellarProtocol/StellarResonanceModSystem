# IGameDataWorld.GetMonsterByEntity method

Resolves the [`MonsterInfo`](../../Stellar.Abstractions.Domain.GameData/MonsterInfo.md) for a live entity by reading the entity's config/template id from the cached combat-wire attribute (attr id 10 = `AttrTypeIds.AttrId`), then looking up the monster table. Returns `null` when the entity has no cached attr-10 value, when the config id is absent from the monster table, or when the monster table has not yet been loaded.
