# IWindowControl.SetVisiblePersist method

Show or hide the window AND persist the choice to the active layout slot (per resolution), so it is restored on the next relaunch. This is the single source of truth the framework reapplies on launch — the layout-editor eye-toggle writes the same slot. Use it for user-driven visibility toggles (hotkeys, close buttons) instead of [`SetVisible`](./SetVisible.md) plus a private config key, which desyncs from the slot and loses to it on relaunch.
