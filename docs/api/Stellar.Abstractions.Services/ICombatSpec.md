# ICombatSpec interface

Per-entity active sub-profession (spec) resolved from observed combat casts.

There is no authoritative spec field on the combat wire, and the equipped-skill loadout (`AttrSkillLevelIdList`) carries both specs' signature skills, so it cannot disambiguate. The framework instead recognises spec-defining skill ids as damage/heal events flow through (last-seen-wins, so a mid-fight spec change is followed) — the same method the ZDPS-family meters use. Resolve the display name via [`Name`](../Stellar.Abstractions.Domain.GameData/ProfessionSpecs/Name.md) and the gear talent-school via [`TalentSchool`](../Stellar.Abstractions.Domain.GameData/ProfessionSpecs/TalentSchool.md).
