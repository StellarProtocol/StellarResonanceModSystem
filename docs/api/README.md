# API reference — moved to the docs site

The generated reference for the plugin API (`Stellar.Abstractions`) now lives at
**<https://docs.stellarresonance.app/api/>** — start at
[`IPluginServices`](https://docs.stellarresonance.app/api/stellar-abstractions-services/ipluginservices/).

It is rebuilt from the XML docs in `src/Stellar.Abstractions` on every docs deploy, so it always matches `main`.
(The Markdown copy that used to live in this folder was generated by hand and had fallen out of date.)
To read it offline, build the site: see [`../../docs-site/README.md`](../../docs-site/README.md).
