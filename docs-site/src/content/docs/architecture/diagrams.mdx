## Editing a diagram

Edit the JSON under `docs/diagrams/src/`, then run `docs/diagrams/build.sh --svg` to re-validate every diagram, re-render the interactive versions and refresh the committed SVGs. See [`docs/diagrams/README.md`](https://github.com/StellarProtocol/StellarResonanceModSystem/blob/main/docs/diagrams/README.md).
